## Online and Federated Learning for Predictive Maintenance

*In collaboration with Scania AB*

<div align="justify">
New heavy-duty vehicles have multiple actuators and sensors that are used generate and record time-series data streams, respectively. These data streams can be used model what normal operations in trucks are supposed to look like and by extension can also be used to identify anomalies. We implemented a transformer-based variational autoencoder to detect anomalies in truck operations for predictive maintenance.
